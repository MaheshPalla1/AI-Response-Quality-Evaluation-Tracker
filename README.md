
# AI Response Quality Evaluation Tracker

## Project Overview

An Excel-based tracker designed to evaluate AI-generated responses based on accuracy, relevance and clarity.

## Key Features

- AI prompt and response tracking
- Accuracy, relevance and clarity scoring
- Automated overall quality score calculation
- Evaluation status using IF formulas
- Conditional formatting
- Performance dashboard and charts

## Tools Used

- Microsoft Excel
- IF, AVERAGE, COUNTIF and COUNTA formulas
- Conditional Formatting
- Data Visualization

## Dashboard

The dashboard provides an overview of total evaluations, good responses, responses requiring improvement and average quality scores.

## Project Objective

To demonstrate practical skills in AI response evaluation, data analysis, quality assessment and Excel dashboard creation.
